DATABASES PROJECT.
There is a videogame called "Madoka Magica Magia Exedra". It is kind of your standard gacha affair, you have gambling systems called fateweaves for the playable characters called Kiokus.
These Kioku have multiple methods of being upgraded. about 4 different leveling up systems. XP, Magic, Skills, Heart, and ascension.
These different upgrade methods require using different in-game materials to do. XP leveling requires XP, Magic leveling requires shards gems orbs and cores, Skills leveling requires scrolls codexes and grimoires, Heart Leveling requires heart sand, and Ascension requires duplicates of the Kiokus.
These various materials can be obtained via playing the main story of the game, completing challenges (some of which are limited time), or by buying them in the in-game store using in-game curiencies (some of which are limited time) gotten through gameplay (mainly pvp battles, events, and raids).
Prior to entering this databases class, I had created a google sheet that would help me see what materials I should spend the limited in-game curriencies on to better level up my characters.
My project will exist as an evolution of this sheet.
It will be a java program that creates SQL files. These SQL files will be able to: create the database and it's table in a more normalized easier to use form, add any obtained Kioku to the database, be able to hold the currently obtained material count, and be able to query the database for what matierials are the most importaint to obtained for any or all kioku in the database.
I have not yet decided if this program will use JFrames or The Terminal for user input. I am more concerned on the database side of things RN.
